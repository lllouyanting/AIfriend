# 隐私与数据

- **本机档案**：人设、聊天、日程、头像和确认后的记忆保存在本机应用数据目录。测试安装包不包含开发者的个人档案。
- **AI 推理**：为理解消息及生成回复，相关人设、聊天上下文和检索到的记忆会经开发者的阿里云代理发送至模型服务；不能理解为“所有内容都不离开电脑”。
- **联网查询**：相关查询条件会发送至搜索或地图/天气服务。默认不等于上传全部聊天，但查询本身可能包含用户提供的地点或关键词。
- **设备与额度**：设备凭据保存在本机，云端保存额度与反馈提交状态，用于鉴权和用量控制；共享供应商密钥不放入客户端。
- **问题反馈**：提交的问题说明及用户选择附带的上下文会进入开发者的飞书表格，用于排查问题；提交前可检查内容。
- **删除范围**：本地初始化清除当前个人档案，不自动删除已上传反馈，也不撤回已经提交给服务商的请求。卸载程序通常保留本机档案。

本项目尚在小范围体验阶段。请避免发送密码、API 密钥或不希望交由在线服务处理的信息。云端故障或体验额度用尽会影响 AI 功能，本地记录仍保留。
