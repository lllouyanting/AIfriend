# AFriend 使用说明

适用：Windows x64 桌面版 0.9.16。

## 安装与入口

运行安装程序后打开 AFriend，首次设置角色、相处方式、头像与权限。无需登录账号或填写 API 密钥。拖动蘑菇移动位置，单击展开应用；三个页面分别为聊天、日程、设置。右上角方框切换大小，叉号收起。收到新消息时蘑菇上方显示提示，点击进入聊天。

真正退出请使用托盘菜单。更新安装保留本机档案；卸载通常也保留档案，删除个人内容请在应用内初始化。

## 聊天与日程

可以连续发送短消息，应用结合语境回复。记日程时说明事项和时间，缺少的信息会继续询问；普通聊天里的打算不等于要求操作日程。日历支持手动添加、修改与取消单次日程，目前不支持周期、批量或天气自动触发提醒。

事项时间与提醒时间分开。提醒晚于事项时会先确认；修改已取消记录时先确认是否恢复提醒。

| 状态 | 含义 |
|---|---|
| 待提醒 | 尚未到时，或仍在允许的发送重试窗口内 |
| 已提醒 | 提醒消息实际写入聊天，不表示用户已读或已经做完 |
| 已错过 | 超过提醒时间 30 分钟仍未发送 |
| 未发送 | 提醒被关闭期间到期，没有发送 |
| 已取消 | 用户取消，保留记录且不再提醒 |

提醒需要程序运行、网络与模型服务。短暂失败会在到期后 30 分钟内重试，超过窗口不继续补发；关闭提醒期间到期的记录，重新开启也不会自动补发。不能保证退出、关机、持续断网时准时送达。

## 主动消息

低、中、高频分别为 4、2、1 小时。当天首次启动可触发一次；连续断网满当前频率对应时长后恢复连接，也可触发一次。免打扰期间不发，退出后停止。

后续计时从最近一条对话消息开始；聊天结束后重新计时。普通主动消息未获回复时，不按小时反复追发。话题从勾选项中随机选择，联网话题受资料与服务可用性影响；“查看来源”打开所用新闻链接。

## 人设、方言与记忆

设置人物、说话方式、边界及方言，可保存与恢复风格版本。方言资料不足或改写失败时可能保留按人设生成的草稿，不保证每句话都有方言词。

“ta 记得的事”支持手动维护，以及从近期聊天整理待确认候选，确认后才作为有效记忆使用。每隔 3 天会出现发光红点，打开该设置模块即可清除，不要求运行整理。相近候选会尽量去重，喜好仅在相关话题中作为倾向，不代表当下正在进行某项活动。

## 连接、额度与反馈

AI、联网查询和反馈上传需要网络。额度不足、连接失败与日程缺信息属于不同情况，请查看实际状态提示。已确认的体验方案为：所有设备共享模型预算20元/天，每设备300轮/天，北京时间次日零点恢复。联网搜索不额外设每日次数，但受供应商共享额度限制。模型预算不包含云资源、搜索等其他服务费用，采用保守估算；个人轮次是上限，不保证共享预算足够每人用满。云端额度保护已启用。

可通过反馈描述问题，并自行选择是否附带上下文。反馈会提交至开发者的飞书表格；上传失败先存本地待重试。请不要在反馈中提交密钥、密码等敏感内容。

## 初始化所有数据

确认后清理本机个人档案并回到首次设置，保留共享方言资料与设备凭据；不是备份或恢复操作。已上传的反馈不会随本地初始化自动删除。详见[隐私与数据](隐私与数据.md)。
