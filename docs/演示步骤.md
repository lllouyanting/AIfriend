# 5 分钟演示步骤

1. 安装并打开，设置一个人物及其说话风格。拖动蘑菇，体验展开、收起与页面切换。
2. 发送普通问候，再发送一条较长消息，观察短气泡、等待动画和窄窗显示。
3. 请求创建一个几分钟后的提醒，随后修改其提醒时间；打开日历核对内容。保持应用与网络运行，等到提醒出现。
4. 询问指定城市当前天气，或近期新闻；检查回答内容，并查看消息下方的查询服务小字；小字不提供网页跳转。
5. 在设置里切换方言，再进行一轮聊天。手动添加一条喜好，分别聊相关与无关话题，观察记忆使用。
6. 收起应用，检查蘑菇提示；退出并重新打开，检查档案是否保留。

演示前确认在线体验服务可用且额度未用尽。清空测试数据时使用“初始化所有数据”，勿用个人正式档案演示删除流程。
